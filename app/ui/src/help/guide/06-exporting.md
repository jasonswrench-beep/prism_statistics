# Reports and exporting

## Exporting the output

**File › Export** writes every result on the Output screen in one of these formats:

- **Word (.docx)**: APA tables and figures you can edit.
- **HTML**: one page that opens in any browser.
- **PDF (tagged, accessible)**: a PDF with headings, table structure, and alternative text for screen readers.
- **R script**: R code that repeats the analyses, for checking the numbers in R or sharing them with someone who uses R.

## One figure or table

Under each figure, **Save PNG** saves it as an image for slides or a poster, at three times screen size. **Save SVG** saves it as a vector image that stays sharp at any size.

Under each table, **Copy table** copies it as shown, ready to paste into a spreadsheet or a document. **Save CSV** saves it as a CSV file with the numbers at full precision, for further calculation.

## Building a report

The **Report** screen arranges what goes into a document:

- which results, and in what order
- which parts of each result (figures, tables, checks, paragraph, method note)
- your own headings and text between them (write `*word*` for italics)

The arrangement is saved with the project. **Export to Word**, **HTML** or **PDF** on that screen writes the report and numbers its tables and figures in order.
