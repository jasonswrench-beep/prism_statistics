# Keyboard shortcuts

| Keys | Does |
|---|---|
| Ctrl+O | Open data |
| Ctrl+Shift+O | Open project |
| Ctrl+S | Save project |
| Ctrl+Shift+S | Save project as |
| F1 | Help for the dialog in front, or this guide |
| Ctrl+Shift+H | Open or close Help me choose |
| Ctrl+Z | Undo the last change |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+F | Find a value in Data View |
| Ctrl+G | Go to a case or variable |
| Esc | Close the dialog in front |
| Tab, Shift+Tab | Move between the controls of a dialog |
| Enter or Space | Choose the focused button |

To put a variable into one of a dialog's boxes, select it in the variable list and choose the arrow button beside the box.
