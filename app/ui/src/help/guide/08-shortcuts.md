# Keyboard shortcuts

| Keys | Does |
|---|---|
| Ctrl+O | Open data |
| Ctrl+Shift+O | Open project |
| Ctrl+S | Save project |
| Ctrl+Shift+S | Save project as |
| F1 | Help for the dialog in front, or this guide |
| Ctrl+Shift+H | Open or close Help me choose |
| Ctrl+Z | Undo the last change |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+F | Find a value in Data View |
| Ctrl+G | Go to a case or variable |
| Esc | Close the dialog in front |
| Tab, Shift+Tab | Move between the controls of a dialog (the focus stays in the dialog) |
| Up, Down, Home, End | Move through a variable list |
| Enter or Space | Choose the focused button, or pick the focused variable |

To put a variable into one of a dialog's boxes, select it in the variable list and choose the arrow button beside the box. From the keyboard: Tab to the list, move to the variable with the arrow keys, and press Enter twice (once to pick it, once to move it into the first box that takes it). The focus stays in the list for the next variable. A dialog opens with the focus on its first control, and after Run the focus is on the new result.
