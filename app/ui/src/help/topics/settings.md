# Settings

Preferences for you on this computer. They aren't saved in a project, so they stay the same whichever project you open.

## How to open it
Choose **Tools › Settings…**.

## Options
- **Text size**: **Standard** (default), **Larger (115%)** or **Largest (130%), for a projector**. The whole window changes at once.
- **Data View: Show value labels when it opens**: off by default. You can still switch labels on and off in Data View.
- **Data View: Open browse-only**: on by default, so cells can't be changed by accident. Turn **Browse only** off in Data View to edit.
- **Analyses: Confidence level new dialogs start with**: 95 by default. Any level from 50 up to, but not including, 100. Each dialog can still change it, and results already run keep the level they used.
- **AI writing…** and **Connect an AI assistant…** open those settings.

**Restore defaults** puts every setting back. Changes apply from the next dialog or Data View you open.

## What isn't a setting
Decimal places follow APA style for each statistic (p values, for example, to three places). That way the window, Word, HTML and PDF always show the same numbers.
